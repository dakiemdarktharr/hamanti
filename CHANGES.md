# hamanti implementation files

The original 300 styles, descriptions, and eight groups are preserved. All four source content files remain unchanged; the original README is retained in source-notes.

The app now has the hamanti identity, reduced interface copy, Motion/Lenis interactions, botanical scenery, a fixed React Bits Topography background per style, and eight selected references per style. Image bytes live in MongoDB; GitHub contains source code and attribution metadata.
